## What shipped

- `src/engine.rs` (new) — deterministic, side-effect-free workflow engine:
  - `analyze`: typed DAG fail-closed analysis (exactly one `start`, every edge endpoint declared, acyclicity, boundedness — every node reachable from `start` and able to reach a `terminal`).
  - Privilege/role rules: node `params` may not carry authority keys; `role` must be a default role or a hash-pinned custom role.
  - Pinning: config pin id+hash must match the loaded document; changed-in-flight detection for pinned instances.
  - Review-gate (distinct reviewer reachable before any `merge`; reviewer/implementer identity separation).
  - Review-round policy: at most 3 normal fix rounds automatically, one separately authorized recovery round, exhaustion -> human queue.
  - Advisory steps: proposals/evidence only, no transition authority.
  - Route-grant revision binding; fresh single-use pause/resume digests; per-item terminal blockers; follow-up routing; one-authoritative-workflow-per-scope check.
  - Bundled Doctrine default workflow (`fleet-doctrine-1`) embedded with pinned sha256.
- `src/schema.rs` — `Family::Workflow` (`hf-workflow/v1`) mirrored in Rust: closed 9-kind node registry, `validate_workflow`, canonical-bytes enforcement extended to Plan|Workflow, `SUPPORTED_FAMILIES` 15 -> 16.
- `src/state.rs` — durable engine state:
  - Migration chain: `SCHEMA_VERSION` 1 -> 2, sequential m0001 -> m0002 runner; m0002 adds the workflow-engine columns to `instances` (workflow pin, current node, review-round counters, human-queue/terminal-blocker flags, pause flag + resume digest).
  - `issue_grant` (validated `hf-grant/v1` bindings incl. epoch; duplicates and wrong-epoch refusals), `grant_by_id`, `invalidate_grant`.
  - `start_instance` (pins grant workflow/policy hashes + issue binding; refuses inactive grants), `pause_instance`, `resume_instance` (engine-authorized fresh digest, single-use), `advance_instance` (persists node/rounds/blockers/status), `instance_by_id`, `list_instances`.
- `schemas/fixtures/workflow/workflow.doctrine.json` (new canonical source, 845 bytes) + `schemas/fixtures/manifest.jsonl` row (`kind: doctrine`) — oracle holds 62 expectations.
- Docs: see the docs table below.
