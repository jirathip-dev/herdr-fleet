## What this slice delivers

A typed read-only core for the herdr-fleet companion CLI, per the #3
contract corpus under docs/contracts/:

- src/value.rs — closed lossless JSON/TOML value model with a strict parser.
- src/canonical.rs — canonical JSON (sorted keys, ASCII escaping, trailing
  LF) and SHA-256 digests per schema-registry.md.
- src/formats.rs — identity/slug/hex/plan-id/semver validators.
- src/redact.rs — one shared adapter-boundary redaction pass (spec-cli §6).
- src/time.rs — RFC3339 seconds-precision UTC formatting.
- src/schema.rs — Rust mirror of scripts/check-contract-fixtures.py for all
  seven families: hf-config, hf-policy, hf-output, hf-error, hf-observation,
  hf-plan, hf-capability (unknown versions refused as refuse-version).
- src/config.rs — hf-config/v1 + hf-policy/v1 discovery/load/typed model;
  explicit --config wins, else the XDG default; single named overlay.
- src/process.rs — bounded subprocess runner: env allowlist (env_clear +
  allowlist only), null stdin, piped output, deadline kill, optional cwd.
- src/observe.rs — git/herdr/gh read adapters, bounded concurrency, per-run
  timing evidence, and acceptance revisions bound over the redacted text.
- src/plan.rs — deterministic hf-plan/v1 rendering; digest = sha256 over the
  canonical plan bytes; issue-number/ref/revision changes flip the digest.
- src/commands.rs + src/main.rs — config init|validate|show, doctor, status,
  plan, capabilities; single hf-output/v1 envelope on stdout in --json mode;
  diagnostics on stderr; exit codes 0/1/2/3/4/5.
- tests/cli_smoke.rs (rewritten) and tests/cli_readonly.rs (new) — real
  binary behavior tests with fake herdr/gh on a controlled PATH and
  synthetic local git repositories; hostile config paths and issue text
  never reach a shell or break JSON framing.
- Docs updated to the read-only-core state: README.md, docs/DEVELOPMENT.md,
  skills/herdr-fleet/SKILL.md.

Read-only guarantees are load-bearing, not prose: the binary never
installs/starts/stops Herdr, never mutates a repository, and adapter reads
are env-isolated and redacted at the boundary.
