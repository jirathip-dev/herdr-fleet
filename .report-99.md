## What changed (test-side only — no production behaviour change)

- `tests/mutation_engine.rs` — the repeat-archive leg of
  `dirty_cleanup_archive_preserves_exact_bytes_and_manifest_and_never_deletes`
  no longer asserts a wall-clock outcome. The raw apply response is accepted
  as either legal outcome and asserted strictly within each branch:
  - same-second collision → typed refusal (`error.code ==
    effect.archive.failed`, kept from the old assertion); or
  - next second → a second archive under a DIFFERENT directory name, itself
    complete: 3 entries, `removed:false`, every entry's bytes/sha256
    re-verified on disk, and `manifest.json` digest equal to that archive's
    reported `manifest_sha256`.

  In BOTH branches the clock-independent invariant is asserted: the FIRST
  archive directory (captured at step 67) is byte-unchanged — `manifest.json`
  digest still equals the recorded `manifest_sha256`, and every recorded
  manifest entry still matches its bytes and digest on disk. The dirty lane
  payload must also still be in place. `assert_eq!` / `assert_ne!` only; no
  assertion was weakened or deleted (`files.len() == 3`, payload digest,
  manifest-digest pinning all remain).
- `src/lifecycle.rs` — new deterministic unit test
  `archive_tree_refuses_an_existing_destination_without_touching_it` beside
  `archive_refuses_symlinks_and_fails_closed`: pre-creates `dest` with
  content, calls `archive_tree`, asserts `err.code == archive_code::FAILED`
  and that the pre-existing destination content is untouched (nothing copied
  in, no manifest written). This addition sits inside `#[cfg(test)] mod
  tests`; production code is untouched.
